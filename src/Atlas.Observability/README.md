# Atlas.Observability

Infrastructure for allowlisted JSON diagnostics, local metric observations and .NET activity traces. Business event contracts and operation context live in Atlas.Contracts; SQL audit/outbox mappings live in Atlas.Persistence; Console owns lifetime/configuration and the local delivery worker.

Start with [the running implementation guide](../../docs/security/observability/LOCAL-DEVELOPMENT.md). Local files are inspection output, not a replacement for SQL audit history or cloud durable acceptance.
